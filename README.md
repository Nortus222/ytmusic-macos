# ytmusic-macos
A native macOS YouTube Music client focused on responsive browsing and reliable audio playback.

Status: brainstorming and feasibility planning. There is no runnable app yet.

Start with the [brainstorming and wayfinder issue](https://github.com/Nortus222/ytmusic-macos/issues/1). Read the [implementation plan](docs/PLAN.md) for the proposed scope, open technical choices and verification gates.
